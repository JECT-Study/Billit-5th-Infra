# 팀원 서버 접속 안내 (단톡방용)

대상: BE 박상혁, 김준원 / FE 백단아, 성민서. 보낸 사람만 계정을 만든다.
아래 선 사이를 그대로 복사해서 보낸다.

---

[서버 접속 안내]

서버는 OCI에 3대 있어요. 운영 앱, 운영 DB, 개발(+모니터링).
인터넷에 ssh 포트를 열어두진 않았고, Tailscale이라는 사설망 앱으로 들어가요. 처음이면 10분 정도 걸려요.

**1. 저한테 보내주실 것 (개인 메시지로)**

- ssh 공개키 한 줄
- Tailscale 초대 받을 이메일 (구글/깃허브 계정 쓰는 이메일이면 돼요)

공개키는 터미널에서

```
ssh-keygen -t ed25519 -C "이름@ject"
cat ~/.ssh/id_ed25519.pub
```

윈도우는 PowerShell에서 첫 줄은 같고, 두 번째 줄만 `type $env:USERPROFILE\.ssh\id_ed25519.pub` 이에요.
이미 키 있으면 만들지 말고 두 번째 줄만요.
`ssh-ed25519 AAAA...` 로 시작하는 한 줄을 보내주시면 되고, **.pub 안 붙은 파일은 개인키니까 보내지 마세요.**

**2. Tailscale 설치**

- https://tailscale.com/download 에서 받아서 설치 (맥은 앱스토어에도 있어요)
- 제가 초대하면 메일이 와요. 메일의 링크를 누르고, 1번에서 알려준 이메일 계정으로 로그인하면 끝.
- Tailscale 앱이 켜져 있어야(메뉴바/트레이 아이콘) 서버가 보여요.

**3. 접속**

`~/.ssh/config` 파일에 아래를 넣어주세요 (윈도우는 `C:\Users\본인이름\.ssh\config`). 없으면 새로 만들면 돼요.
`아이디`는 제가 계정 만들고 알려드릴게요.

```
Host ject-dev ject-prod-app ject-prod-data
  User 아이디
  IdentityFile ~/.ssh/id_ed25519
```

그러면

```
ssh ject-dev          # 개발 서버
ssh ject-prod-app     # 운영 앱 서버
ssh ject-prod-data    # 운영 DB 서버
```

처음 접속할 때 fingerprint 물어보면 yes. 비밀번호는 없어요.

**4. 서버에서**

- 세 대 다 sudo 돼요.
- 배포는 CI가 하니까 docker compose 직접 올리고 내리진 말아주세요. 상태 보는 건 `sudo ject-deploy status dev` 처럼.
- /srv/ject/secrets 안은 열어보지 않기.
- 운영 DB 서버는 보는 건 괜찮은데 뭔가 지우거나 바꿀 땐 저한테 먼저 말해주세요.

Grafana(로그, 지표)는 `ssh -N -L 3000:127.0.0.1:3000 ject-dev` 하고 브라우저에서 localhost:3000 이에요. 계정은 따로 만들어드릴게요.
