[JECT 개발 서버 접근 준비]

개발 서버(OCI) 3대가 준비됐어요. 각자 본인 계정으로 접속할 수 있게, 아래 두 가지만 보내 주세요.

1. OCI 콘솔 초대를 받을 이메일 주소
2. SSH **공개키** 한 줄 (`.pub` 파일 내용). **개인키(`id_ed25519`, `.pub` 없는 파일)는 절대 보내지 마세요.**

공개키 만드는 법

- macOS / Linux 터미널
  ```
  ssh-keygen -t ed25519 -C "이름@ject"
  cat ~/.ssh/id_ed25519.pub
  ```
- Windows PowerShell
  ```
  ssh-keygen -t ed25519 -C "이름@ject"
  Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub
  ```
  (이미 키가 있으면 만들지 말고 `cat`/`Get-Content`만 하면 돼요. 암호(passphrase)는 설정하는 걸 권장해요.)

`ssh-ed25519 AAAA... 이름@ject` 처럼 생긴 한 줄을 보내 주면 됩니다.

받으면 제가 해 드리는 것

- 서버 3대(운영 앱·운영 데이터·개발)에 본인 이름의 리눅스 계정(sudo 가능)
- OCI 콘솔 초대 메일(JECT 자원 조회 + Bastion 접속 세션 생성만 가능). 첫 로그인 때 MFA 등록이 필요해요.
- 접속 방법 안내(`infra/access/README.md`)와 접속 정보 파일(`access.env`)

서버 SSH는 인터넷에 열려 있지 않고 OCI Bastion을 거쳐서만 들어가요. 운영 DB·Redis는 운영 앱 서버에서만 접근돼요.

## 받은 뒤 관리자 절차 (성주)

1. 공개키를 `.local/ject-access/<username>.pub`에 저장하고 `infra/access/team.yaml`에 경로·이메일 기록
   (username: sanghyuk / junwon / dana / minseo)
2. 3대 각각: Bastion으로 접속 → `sudo /opt/ject/bin/ject-user add <username> /tmp/<username>.pub "<이름>"` → `ject-user list`로 지문 확인
3. OCI: Identity → Domains → Default → Users → 이메일로 사용자 생성 → 그룹 `ject-developers`에 추가
4. `.local/ject-access/access.env`(OCID·사설 IP, 비밀값 아님)를 본인에게 전달 → `~/.config/ject/access.env`에 두게 안내
5. 본인이 `infra/access/ject-ssh.sh <username> dev`로 접속되는지 확인받기
